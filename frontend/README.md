# 📱 ShramLedger Frontend — Enterprise Web Application

High-performance Single Page Application (SPA) built on **React 19**, **Vite 8**, and **Tailwind CSS**.

---

## 🎨 Key UI Components & Architecture

- **`LandingPage.jsx`**: Enterprise product showcase with an interactive Construction Site ROI Calculator, Commercial SaaS Pricing Matrix, and Proposal Generator.
- **`CommercialQuoteModal.jsx`**: Real-time quotation calculator with customizable site counts, workforce sizing, and commercial proposal generation.
- **`EmployerPortal.jsx`**: Contractor & EPC Site Management Hub with Bulk Muster Roll CSV/Excel ingestion, SHA-256 Merkle Ledger batch anchoring, and Statutory BOCW Act Form XXIX compliance reporting.
- **`LenderPortal.jsx`**: Bank & NBFC Underwriting Terminal with custom policy risk evaluator, instant loan sanction simulator, and live B2B API Key manager.
- **`NgoGovPortal.jsx`**: State Labor Mission analytics and automated direct scheme dispatch (e-Shram, PM Vishwakarma, BOCW, SVANidhi).
- **`AdminFraudDashboard.jsx`**: Anti-fraud intelligence radar with shift collision detection and immutable audit log streams.
- **`IncomeCertificate.jsx` & `PublicVerifier.jsx`**: Cryptographically verifiable Digital Work Passport with QR code scanning and Merkle tamper inspector.

## 🛠️ Development & Build Commands

```bash
# Install dependencies
npm install

# Start Vite local development server
npm run dev

# Build production bundle
npm run build

# Preview production build locally
npm run preview
```
