Cryptographic Math

Merkle Tree Construction & Math (ledger.py)

Mathematical implementation of the tamper-evident hash tree algorithm.

📐
Recursive Construction Algorithm

Entries are hashed deterministically and combined in pairs up to the single Merkle Root.

# 1. Leaf Hash
leaf_hash = hashlib.sha256(canonical_json(entry)).hexdigest()

# 2. Recursive Level Pairing
for i in range(0, len(nodes), 2):
  combined = nodes[i] + nodes[i + 1]
  parents.append(hashlib.sha256(combined.encode()).hexdigest())
🔍
Proof of Inclusion & Verification

Lenders can verify any individual wage record in O(log N) operations using co-hashes.

# Audit Path Verification
current_hash = target_leaf_hash
for sibling_hash, is_left in audit_path:
  pair = (sibling_hash + current_hash) if is_left else (current_hash + sibling_hash)
  current_hash = hashlib.sha256(pair.encode()).hexdigest()
assert current_hash == expected_merkle_root
  • Zero personal data disclosure required for verification.
  • 1,024 work entries require only 10 hashes to prove validity.

Data Science & Security

ShramScore Formula & Statistical Fraud Radar

Mathematical rigor ensuring bank-grade risk assessment and fraud resistance.

🧮
CreditScorer Mathematical Formulation
Score = 300 + 600 * (
  0.25 * Wage_Consistency +
  0.25 * Work_Continuity +
  0.20 * Employer_Endorsement +
  0.15 * Digital_Trail_Ratio +
  0.15 * Evidence_Strength
)
  • Wage Consistency: 1 - min(1.0, std_dev(wages) / mean(wages)).
  • Work Continuity: min(1.0, verified_days_in_last_90 / 66).
  • Income Projection: Kernel density estimate with 95% confidence interval.
🚨
FraudDetector Statistical Anomaly Rules
  • Wage Dispersion Outlier: Flags claims exceeding 2.5 standard deviations from regional trade average.
  • Duplicate Time Punch: Detects overlapping working hours claimed across multiple contractors on the same day.
  • Ghost Contractor Pattern: Flags contractor phone numbers that endorse 100+ workers with zero verified tax IDs.
  • Geographic Velocity Anomaly: Flags entries logged hundreds of kilometers apart within impossible time intervals.
